Weather Icon Display (Static Data)

📌 Project Description

Weather Icon Display is a simple and responsive web application developed using HTML5, CSS3, and JavaScript. It allows users to select a weather condition from a dropdown menu and displays the corresponding weather icon, title, description, and background color.

The project uses static data stored in a JavaScript object and does not require any external weather API.

🎯 Objectives

- Practice JavaScript objects and DOM manipulation.
- Understand event listeners and conditional rendering.
- Display dynamic content based on user selection.
- Create an attractive and responsive user interface.

🛠️ Technologies Used

- HTML5 – Structures the webpage.
- CSS3 – Provides styling, animations, and responsive design.
- JavaScript – Handles weather selection and dynamic updates.

✨ Features

- Dropdown menu with seven weather conditions.
- Matching icons and descriptions for each condition.
- Dynamic background colors based on selected weather.
- Default display before a condition is selected.
- Smooth transitions and floating icon animation.
- Responsive design for desktop and mobile devices.
- No API key or backend required.

🌦️ Weather Conditions

1. Sunny ☀️
2. Cloudy ☁️
3. Rainy 🌧️
4. Stormy ⛈️
5. Snowy ❄️
6. Windy 💨
7. Foggy 🌫️

🚀 How to Run

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that "index.html", "style.css", and "script.js" are in the same folder.
4. Open "index.html" in a web browser, or use the Live Server extension.
5. Select a weather condition from the dropdown to view its icon and description.

- JavaScript objects and key-based data access.
- DOM selection and manipulation.
- Event handling using the "change" event.
- Conditional rendering and default states.
